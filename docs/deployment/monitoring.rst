Monitoring
==========

This section covers system monitoring and observability for LUStores.

Overview
--------

Monitoring capabilities are provided through the System Management API.

System Status
-------------

Real-time system status is available through the System Management API endpoints. See :doc:`../testing-guide` for comprehensive monitoring capabilities.

Testing
-------

Monitoring functionality is tested as part of the System Management test suite. See :doc:`../testing-guide` for details.
