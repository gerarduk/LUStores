# 📱 Mobile Camera Scanner Guide

## Quick Overview
The camera scanner lets warehouse staff use their mobile devices (phones/tablets) to scan QR codes and barcodes directly from shelves and immediately add items to quotes. No special hardware needed!

---

## 🎯 Perfect For
- Warehouse staff walking through aisles
- Inventory counts with mobile devices
- Quick quote creation on the floor
- Shelf-to-quote workflows
- No need for USB scanners or separate equipment

---

## 🚀 Getting Started

### Step 1: Open on Mobile Device
1. Open LUStores in your mobile browser (Chrome or Safari recommended)
2. Navigate to **Sales & Quotes**
3. Tap the **Browse Items** tab
4. You'll see the **QR/Barcode Scanner** card at the top

### Step 2: Grant Camera Permission
1. Tap **"Start Camera"** button
2. Browser will ask for camera permission
3. Tap **"Allow"** or **"OK"**
4. Camera preview will appear

### Step 3: Scan Items
1. Point your camera at the QR code or barcode on the shelf
2. Keep camera 4-6 inches away from the code
3. Hold steady for 1-2 seconds
4. ✅ Item automatically added to your quote!
5. Continue scanning more items

### Step 4: Review & Process
1. When done scanning, tap **"Stop Camera"**
2. Review your quote items
3. Enter charge code
4. Process the quote
5. Get picking list for fulfillment

---

## 📸 Scanning Tips

### For Best Results
- ✅ **Good lighting** - Scan in well-lit areas
- ✅ **Hold steady** - Keep camera still while scanning
- ✅ **Right distance** - 4-6 inches from the code
- ✅ **Clean lens** - Wipe camera lens if blurry
- ✅ **Back camera** - Uses rear camera automatically on phones

### Supported Code Types
- QR Codes (most common)
- EAN-13 (retail barcodes)
- EAN-8 (short barcodes)
- Code 128 (warehouse codes)
- Code 39 (industrial codes)
- UPC-A (US retail)
- UPC-E (compact UPC)

## 🔧 Troubleshooting

### Camera Won't Start
**Problem**: "Camera access denied" or no preview

**Solutions**:
1. Check browser settings for camera permissions
2. Settings → Safari/Chrome → Camera → Allow for site
3. Close other apps using the camera
4. Refresh the page and try again

### Codes Not Scanning
**Problem**: Camera shows but doesn't detect codes

**Solutions**:
1. Move closer/farther from the code (try 4-6 inches)
2. Improve lighting (turn on overhead lights)
3. Clean camera lens with soft cloth
4. Ensure code is not damaged or dirty
5. Try holding phone at different angles

### Scan Too Slow
**Problem**: Takes long time to detect

**Solutions**:
1. Ensure code is in the blue scanning box overlay
2. Hold very still for 1-2 seconds
3. Make sure lighting is good
4. Check that code is not reflective/glossy

### Multiple Scans of Same Item
**Problem**: Same item scans twice

**Solution**: Built-in duplicate prevention waits 1.5 seconds between scans of the same code. If quantity should increment, this is correct behavior!

## 🆚 Camera vs Manual Entry

### Use Camera Scanning When:
- ✅ Walking through warehouse
- ✅ Multiple items to add quickly
- ✅ Items have visible QR/barcodes
- ✅ Using mobile device
- ✅ Want hands-free operation

### Use Manual Entry When:
- 📝 Code is damaged/unreadable
- 📝 No camera available
- 📝 At desktop computer
- 📝 Know SKU by memory
- 📝 Camera permissions unavailable

## 🔐 Privacy & Permissions

### What the camera does:
- ✅ Scans codes only (no photos saved)
- ✅ Processes locally in browser
- ✅ No images sent to server
- ✅ Camera stops when you close/stop it

### What the camera does NOT do:
- ❌ Take pictures
- ❌ Record video
- ❌ Access photo library
- ❌ Work in background
- ❌ Share camera feed

## 💡 Pro Tips

1. **Label your shelves** with clear QR codes
   - Generate QR codes from item SKUs
   - Print and laminate for durability
   - Place at eye level on shelves

2. **Use warehouse mode**
   - Enable dark mode for warehouse environments
   - Reduces screen glare in low light

3. **Batch scanning**
   - Scan all items first
   - Adjust quantities later if needed
   - Faster than entering each quantity during scan

4. **Fallback option**
   - Always have manual entry available
   - If camera fails, just type the SKU

5. **Mobile accessories**
   - Phone holder/lanyard keeps device accessible
   - External battery for long scanning sessions
   - Consider rugged case for warehouse environment

## ❓ FAQ

**Q: Does this work on desktop computers?**
A: Yes! Desktop cameras work too, but mobile is more practical for walking around the warehouse.

**Q: Can I scan multiple items quickly?**
A: Yes! The system automatically prevents duplicate scans with a 1.5 second delay between same codes.

**Q: What if the barcode is damaged?**
A: Use the manual entry field below the camera to type the SKU directly.

**Q: Does this work offline?**
A: Camera works offline, but you need internet to validate items and process quotes.

**Q: Can I use a tablet instead of phone?**
A: Absolutely! Tablets often have better cameras and larger screens.

**Q: Will this drain my battery?**
A: Camera uses more power than normal browsing. Close camera when not actively scanning.
