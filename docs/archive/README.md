# Archived Documentation

This directory contains historical implementation notes, fix summaries, and planning documents from the development of LUStores.

## Contents

These files document:

- Implementation summaries for major features
- Bug fix documentation
- Code review findings
- Migration planning documents
- Development checklists
- Expert reviews and recommendations

## Purpose

These files are preserved for historical reference but have been moved out of the root directory to keep the project structure clean. Most of the information has been integrated into the comprehensive Sphinx documentation in the `/docs` directory.

## Current Documentation

For up-to-date documentation, please refer to:

- **User Guides**: `/docs/tutorials/` and `/docs/user-guide/`
- **Developer Documentation**: `/docs/development/` and `/docs/developer/`
- **Deployment**: `/docs/development/deployment-architecture.rst`
- **Database**: `/docs/development/database-organization.rst`
- **Troubleshooting**: `/docs/reference/troubleshooting.rst` and `/docs/operations/system-recovery.rst`
- **Future Plans**: `/docs/roadmap.rst`
